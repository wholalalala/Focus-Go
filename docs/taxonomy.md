# Task taxonomy

Six observed areas are implemented under five broad parent groups:

| Parent | Observed domain | Task |
|---|---|---|
| ATTENTION | SUSTAINED_ATTENTION | rare-target CPT-like |
| ATTENTION | SELECTIVE_ATTENTION | Flanker-like |
| INHIBITION | RESPONSE_INHIBITION | Go/No-Go |
| WORKING_MEMORY | SPATIAL_WORKING_MEMORY / sequential reproduction | forward Corsi-like |
| FLEXIBILITY | RULE_SWITCHING | DCCS-like |
| FOLLOWING_INSTRUCTIONS | MULTI_STEP_EXECUTION | Focus&Go original |

The six UI cards are task-specific observations, not independent latent-factor diagnoses. Spatial sequences involve both spatial and sequential working memory; no separately validated sequential-memory score is claimed. All tasks also depend on comprehension and motor interaction. Classification is organizational, not evidence that a task isolates a single construct.
